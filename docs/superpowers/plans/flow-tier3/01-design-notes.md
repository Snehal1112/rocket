## P4 Undo and redo (F-34)

- Store writes have no history today. Add to `FlowTab`: `history?: { past: GraphSnap[]; future: GraphSnap[]; lastKey?: string; lastAt?: number }`, `GraphSnap = { nodes; edges; callbackHost? }`, cap 100, in memory only. Excluded: `nodeStatus`, `nodeDetail`, `runState`, selection. Verify no tab persistence serialises `history`.
- Pure helpers in `src/lib/flow-history.ts` (push with cap and coalesce, undo, redo) with unit tests.
- The four setters push the previous snapshot to `past` and clear `future`. Optional `{ coalesceKey }` (same key within ~600 ms is skipped) so properties-panel typing is one step. `undoFlow(tabId)` / `redoFlow(tabId)` swap snapshots and set `isDirty: true`. Optional: record a saved snapshot in `markClean` so undoing back to it clears the dirty dot.
- Drag: `FlowCanvas.handleNodesChange` (`~:310-326`) writes every 'position' change, so a drag is one store write per mouse move. Snapshot once per drag (push on `onNodeDragStart`/`onSelectionDragStart`, per-move writes use a `skipHistory` option) or use a 'drag' coalesce key.
- Keys: extend `FlowCanvas.handleKeyDown` (`~:384`): `mod+z` undo, `mod+shift+z` and `mod+y` redo, with the `EDITABLE_TARGET` guard and `preventDefault`. New optional props `onUndo`/`onRedo` wired in `FlowPane`. Toolbar buttons (lucide `Undo2`/`Redo2`, shadcn `Button`) disabled when stacks are empty. Do not add to the global `useKeyboardShortcuts`.
- Pitfalls: undo goes through the store (rfNodes derive from `tab.nodes`); prune `selectedNodeIds` to surviving ids; never push history from `patchFlowNodeStatus`/`patchFlowNodeProgress`/`setFlowRunState`; undoing a deleted Auth node restores the node without its token (`useClearRemovedAuthTokens` cleared it; accepted, document it); clear stale `cycleNodeIds`/`cycleEdgeIds` after undo.
- Issue #45 (Ctrl+A then Backspace deletes the flow) gets a recovery path; include an integration test.
- Tests: `src/stores/__tests__/pane-store.test.ts` (push, cap, coalesce, undo, redo, clear-on-new-edit), `FlowCanvas.test.tsx`, `FlowPane.delete.test.tsx`, `FlowPane.multiselect.test.tsx`. Review task 2 in the main loop (store invariants).

## P7 Step trace backend (F-32, F-38, F-39 backend)

  - `FlowWireValue { edge_id, source_node_id, target_field, value: Option<String>, truncated: bool, credential: bool, error: Option<String> }` (bools skipped when false; value None for credential or error)
  - `FlowRouteEval { kind: String ("if"|"switch"), value: String, matched_case: Option<String> }`
  - (`FlowPollDetail`, `FlowWaitDetail`, `FlowRejectedCall` are P9.)
  - `FlowStepCompleted` carries `trace: Option<Box<FlowStepTrace>>` (like `exchange`).
- Internal plumbing: `NodeTrace` is a `FlowStepTrace` being filled in; pass it into `execute_node` as one new `&mut` out-param next to `poll_stats`; merge it in the run loop where logs/debug/exchange are merged (`~:1063`).
- F-32 duration: wrap the `execute_node` call (`~:1038`) with `Instant::now()`; after the step is built (`~:1070`) do `step.duration_ms.get_or_insert(elapsed_ms)` for every node that ran (including Failed with an error); Skipped stays None. Also cap the uncapped `value` for Input/Transform/Output (`result_to_step` `~:1631-1640`) with the existing `cap_body` (make it `pub(crate)`), masking first and capping second.
- F-39 wire capture: in the Output arm (`~:1228-1252`), the Request wire loop (`~:1290-1330`, values land in `resolved: HashMap<edge_id, String>`, dropped after `apply_wired_overrides` `:555`) and single-input arms (If/Switch/Transform) push one `FlowWireValue` per live data edge. Do NOT use the Input/Transform pattern (`secret_values` only). Capture and mask BEFORE the Request arm rebinds `secret_values` with the send-time credential (`~:1340`). The `auth` target wire is recorded as `{ credential: true, value: None }` and `credentials.auth_for_node` is never read. Caps: `WIRE_VALUE_LIMIT = 16_384` per wire with a `truncated` flag and `WIRE_TOTAL_LIMIT = 65_536` per step (mask first, cap second, reuse `cap_body`). For single-input nodes record that the source's captured output was used (a masked, capped summary), not a re-evaluation.
- F-38 route eval: If arm (`~:1393-1417`) records the coerced `"true"`/`"false"` (the `!!(` coercion stays; tests match on the markers `!!(` and `String(`, comment near `:120`). Switch arm (`~:1418-1440`) records the evaluated string masked with `secret_values` and capped to 1 KB, plus the matched case id or None for default. Also fill `route` on a routing failure.
- F-39 edge-named errors: helper `wire_err(edge, e)` producing `wire '<id>' (<source>.<source_handle> -> <target>.<target_field>): <e>` applied at the three `outcome.result?` sites (Output `~:1244`, Request `~:1322`, `captured_source`), also setting `trace.failed_edge_id`. Never embed the resolved value in an error. `flow_routing.rs:119` ("field 'url' has 2 live inputs") must list edge ids (`NodeFate::Fail(String)` carries them; update the test at `flow_routing.rs:350` and the assertion at `flow_execution_service.rs:4957`). Output "more than one incoming wire" (`~:1238`) lists edge ids. `apply_wired_overrides` messages (`:555-620`) add target field and source node where missing. If one wire errors, earlier wires still return (trace is an out-param, not part of `ExecutedNode`).
- Tests (cargo `-j4 -p rocket-app`, `-p rocket-shared`): wire-shape tests in `events.rs` (new keys omitted when empty so existing exact-JSON tests stay green; old JSON without the new keys deserialises); masked secret wired from an Input; Auth token wired into a header (masked); `auth` wire has no value; over-limit wire truncated; edge-named error plus `failed_edge_id`; Switch value masked; durations set for Input/Output/If/Switch/Transform; style of `an_input_reports_a_secret_masked_but_passes_it_on_raw` (`~:6543`) and `a_transform_reports_a_secret_masked...` (`~:7801`).

- No OpenCollection read needed (no collection/environment model change); no new IPC command; DTO `rename_all` stays camelCase, event top-level keys stay snake_case.

## P11 Run history (F-36)

- Frontend only, in memory, last N = 5 per tab (decision D3). `FlowTab.runHistory?: FlowRunRecord[]` (newest first), `viewedRunId?: string | null` (null = live/latest). `FlowRunRecord = { runId, finishedAt, stoppedReason, environmentName, nodeStatus, nodeDetail, partial? }` (`partial` reserved for P19/P20). Store action `recordFlowRun(tabId, record)` called from `FlowToolbar` right after the final summary is applied (`:275-280`) and in the catch path with `stoppedReason: 'error'`. Optionally strip `exchange` and `logs` from records older than the newest 2 (an exchange can be 256 KB each way).
