# CM6 SingleLineEditor — Plan 07: Field Migration

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Migrate all remaining `VariableAwareInput` call sites to `SingleLineEditor`: `KeyValueEditor` (headers, form body), `PathParamsPanel`, and `AuthEditor` (~12 instances).

**Architecture:** Each migration is a direct prop-for-prop replacement. The `SingleLineEditor` without URL-specific props behaves identically to `VariableAwareInput` — it highlights `{{var}}` tokens, shows popovers on click/hover, and provides autocomplete. The `isSecret` prop replaces `type='password'`.

**Tech Stack:** React, `SingleLineEditor`

**Spec:** `docs/superpowers/specs/2026-04-17-codemirror-single-line-editor-design.md` — "Call Sites — Migration Map"

**Depends on:** Plans 01-06

### Task 2: Migrate AuthEditor

**Files:**
- Modify: `src/components/request/AuthEditor.tsx`

- [ ] **Step 1: Replace the import**

In `src/components/request/AuthEditor.tsx`:

```typescript
// Remove:
import { VariableAwareInput } from './VariableAwareInput';
// Add:
import { SingleLineEditor } from '@/components/editor';
```

- [ ] **Step 2: Replace all VariableAwareInput instances**

There are approximately 12 instances in AuthEditor. Each follows one of two patterns:

**Pattern A — regular text field:**

```tsx
// Before:
<VariableAwareInput
  className='text-sm'
  placeholder='https://auth.example.com/token'
  value={o.accessTokenUrl}
  onChange={(newVal) => patchOAuth2({ accessTokenUrl: newVal })}
  variableContext={variableContext}
  onNavigateToSource={onNavigateToSource}
/>

// After:
<SingleLineEditor
  className='text-sm'
  placeholder='https://auth.example.com/token'
  value={o.accessTokenUrl}
  onChange={(newVal) => patchOAuth2({ accessTokenUrl: newVal })}
  variableContext={variableContext}
  onNavigateToSource={onNavigateToSource}
/>
```

**Pattern B — password/secret field:**

```tsx
// Before:
<VariableAwareInput
  className='text-sm'
  type='password'
  value={o.clientSecret}
  onChange={(newVal) => patchOAuth2({ clientSecret: newVal })}
  variableContext={variableContext}
  onNavigateToSource={onNavigateToSource}
/>

// After:
<SingleLineEditor
  className='text-sm'
  isSecret
  value={o.clientSecret}
  onChange={(newVal) => patchOAuth2({ clientSecret: newVal })}
  variableContext={variableContext}
  onNavigateToSource={onNavigateToSource}
/>
```

Key change: `type='password'` → `isSecret` prop.

Also check for the Bearer token input and Basic Auth password input — they should use `isSecret` too.

- [ ] **Step 3: Handle the onNavigateToSource adapter**

The current `AuthEditor` receives `onNavigateToSource` from `RequestPanel` with signature `(source: VariableSource, key: string) => void`. The `SingleLineEditor` calls `onNavigateToSource(source, key)` — same signature. No adapter needed.
