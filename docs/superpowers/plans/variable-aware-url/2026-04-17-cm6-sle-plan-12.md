### Task 2: Clean up main.tsx

**Files:**
- Modify: `src/main.tsx`

- [ ] **Step 1: Study the current main.tsx structure**

The current `main.tsx` has this structure:

```typescript
import { loader } from '@monaco-editor/react';
// ... other imports

// Theme class application (keep this)

// Monaco worker imports (DELETE)
import editorWorker from 'monaco-editor/esm/vs/editor/editor.worker?worker';
import cssWorker from 'monaco-editor/esm/vs/language/css/css.worker?worker';
import htmlWorker from 'monaco-editor/esm/vs/language/html/html.worker?worker';
import jsonWorker from 'monaco-editor/esm/vs/language/json/json.worker?worker';
import tsWorker from 'monaco-editor/esm/vs/language/typescript/ts.worker?worker';

// MonacoEnvironment setup (DELETE)
self.MonacoEnvironment = { getWorker(...) { ... } };

// Async Monaco init wrapping ReactDOM.createRoot (SIMPLIFY)
import('monaco-editor').then((monaco) => {
  loader.config({ monaco });
  monaco.editor.defineTheme('rocket-light', { ... });
  monaco.editor.defineTheme('rocket-dark', { ... });
  ReactDOM.createRoot(...).render(<App />);
});
```

- [ ] **Step 2: Remove all Monaco imports and setup**

Remove from the top:
```typescript
import { loader } from '@monaco-editor/react';
```

Remove the 5 worker imports:
```typescript
import editorWorker from 'monaco-editor/esm/vs/editor/editor.worker?worker';
import cssWorker from 'monaco-editor/esm/vs/language/css/css.worker?worker';
import htmlWorker from 'monaco-editor/esm/vs/language/html/html.worker?worker';
import jsonWorker from 'monaco-editor/esm/vs/language/json/json.worker?worker';
import tsWorker from 'monaco-editor/esm/vs/language/typescript/ts.worker?worker';
```

Remove `MonacoEnvironment`:
```typescript
self.MonacoEnvironment = { ... };
```

- [ ] **Step 3: Make ReactDOM.createRoot synchronous**

Replace the entire `import('monaco-editor').then(...)` block with:

```typescript
ReactDOM.createRoot(document.getElementById('root') as HTMLElement).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>,
);
```

The app no longer needs to wait for Monaco to load before rendering.

- [ ] **Step 4: Verify the final main.tsx is clean**

The resulting `main.tsx` should look approximately like:

```typescript
import React from 'react';
import ReactDOM from 'react-dom/client';
import './globals.css';
import App from './App';

// Apply theme class synchronously before React renders.
const storedTheme = localStorage.getItem('rocket-theme');
const prefersDark = window.matchMedia('(prefers-color-scheme: dark)').matches;
if (storedTheme === 'dark' || (!storedTheme && prefersDark)) {
  document.documentElement.classList.add('dark');
} else {
  document.documentElement.classList.remove('dark');
}

ReactDOM.createRoot(document.getElementById('root') as HTMLElement).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>,
);
```

Expected: No type errors.

- [ ] **Step 2: Update EditorSkeleton**

In `src/components/editor/EditorSkeleton.tsx`, replace the hardcoded Monaco background colors with CSS variables.

Find:
```tsx
isDark ? 'bg-[#1f1f1f]' : 'bg-white',
```

Replace with:
```tsx
'bg-background',
```

Find any other hardcoded Monaco colors like:
```tsx
style={{ background: isDark ? '#444' : '#ddd' }}
style={{ background: isDark ? '#2d2d2d' : '#ececec' }}
style={{ background: isDark ? '#333' : '#e4e4e4' }}
```

Replace with CSS variable equivalents:
```tsx
style={{ background: 'hsl(var(--muted))' }}
style={{ background: 'hsl(var(--muted) / 0.5)' }}
style={{ background: 'hsl(var(--border))' }}
```

The `useIsDark` hook in `EditorSkeleton` can be simplified or removed if all colors now use CSS variables.
