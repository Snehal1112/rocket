# CM6 SingleLineEditor — Plan 06: URL Bar Migration

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Migrate the URL bar in `RequestPanel.tsx` from `VariableAwareUrlInput` to `SingleLineEditor`. This is the most complex single call site — it uses path params, query params, curl paste, Enter-to-send, and the full scoped variable context.

**Architecture:** Replace the `<VariableAwareUrlInput>` JSX with `<SingleLineEditor>`, mapping all existing props to the new interface. The `VariableAwareUrlInput` import is removed but the file is NOT deleted yet (other migration plans may reference it for comparison). Deletion happens in Plan 08.

**Tech Stack:** React, `SingleLineEditor` from Plans 01-05

**Spec:** `docs/superpowers/specs/2026-04-17-codemirror-single-line-editor-design.md` — "Call Sites — Migration Map"

**Depends on:** Plans 01-05 (core SingleLineEditor complete)

### Task 1: Migrate the URL bar in RequestPanel

**Files:**
- Modify: `src/components/request/RequestPanel.tsx`

- [ ] **Step 1: Study the current VariableAwareUrlInput usage**

In `RequestPanel.tsx`, find the `<VariableAwareUrlInput>` JSX. It currently looks like:

```tsx
<VariableAwareUrlInput
  value={request.url}
  onChange={handleUrlChange}
  onKeyDown={handleUrlKeyDown}
  onCurlImport={handleCurlImport}
  collectionVariables={collectionVariables}
  pathParams={pathParamMap}
  queryParams={queryParamMap}
  onPathParamChange={handlePathParamChange}
  onNavigateToSource={handleNavigateToSource}
  placeholder="Enter URL"
  className="flex-1"
  scopedContext={scopedContext}
/>
```

- [ ] **Step 2: Replace the import**

In `RequestPanel.tsx`, replace:

```typescript
import { VariableAwareUrlInput } from './VariableAwareUrlInput';
```

With:

```typescript
import { SingleLineEditor } from '@/components/editor';
```

- [ ] **Step 3: Replace the JSX**

Replace the `<VariableAwareUrlInput>` with:

```tsx
<SingleLineEditor
  value={request.url}
  onChange={handleUrlChange}
  onSubmit={() => void handleSend()}
  onCurlImport={handleCurlImport}
  variableContext={scopedContext}
  pathParams={pathParamMap}
  queryParams={queryParamMap}
  onPathParamChange={handlePathParamChange}
  onNavigateToSource={handleNavigateToSource}
  placeholder="Enter URL"
  className="flex-1"
/>
```

Key mapping changes:
- `onKeyDown={handleUrlKeyDown}` → `onSubmit={() => void handleSend()}` — the URL keydown handler was primarily for Enter-to-send. The `onSubmit` prop handles this directly. If there were other keyboard shortcuts, they can be added via `onKeyDown` prop.
- `collectionVariables={collectionVariables}` → removed. The `scopedContext` map already includes collection variables (built by `buildScopedContext()`). The CM6 highlight plugin reads from the facet, not raw collection variables.
- `scopedContext={scopedContext}` → `variableContext={scopedContext}` — prop renamed for consistency.

- [ ] **Step 4: Adapt the handleNavigateToSource callback**

The current `handleNavigateToSource` in `RequestPanel.tsx` takes `(source: VariableSource | 'pathParam')`. The new `SingleLineEditor` passes `(source: VariableSource | 'pathParam', key: string)`. Check that the existing callback signature is compatible. If it currently ignores the key parameter, wrap it:

```tsx
// The URL bar only passes source — no key needed.
// The SingleLineEditor passes (source, key) so the signature is compatible
// as long as handleNavigateToSource accepts the extra parameter.
```

If `handleNavigateToSource` only takes one argument, update it to accept the optional second:

```typescript
const handleNavigateToSource = useCallback(
  (source: VariableSource | 'pathParam', _key?: string) => {
    // ... existing logic unchanged
  },
  [/* existing deps */],
);
```

- [ ] **Step 5: Remove unused handleUrlKeyDown if no longer needed**

Check if `handleUrlKeyDown` is used elsewhere. If it was only for the URL input's `onKeyDown`, it can be removed since `onSubmit` now handles Enter. If it handled other shortcuts (e.g., Cmd+L to focus URL bar), keep it and pass via `onKeyDown` prop.

- [ ] **Step 6: Verify compilation**

```bash
npx tsc --noEmit src/components/request/RequestPanel.tsx
```

Expected: No type errors.

- [ ] **Step 7: Commit**

```bash
git add src/components/request/RequestPanel.tsx
git commit -m "feat: migrate URL bar from VariableAwareUrlInput to SingleLineEditor"
```

### Task 2: Manual smoke test

**Files:** No file changes — verification only.

- [ ] **Step 1: Start the dev server**

```bash
cargo tauri dev
```

- [ ] **Step 2: Test basic editing**

1. Click the URL bar → cursor appears, blinking
2. Type `https://example.com/api` → text appears with correct font
3. Select text with mouse drag → selection is visible (blue highlight)
4. Select text with Shift+Arrow → selection works
5. Copy (Cmd/Ctrl+C) and paste (Cmd/Ctrl+V) → works correctly
6. Scroll: type a very long URL → caret stays aligned with text as it scrolls

- [ ] **Step 3: Test variable highlighting**

1. Select an environment with variables (e.g., `baseUrl`)
2. Type `{{baseUrl}}` in URL bar → appears with amber badge color
3. Type `{{unknown}}` → appears with red/destructive color
4. Switch environments → highlight colors update reactively

- [ ] **Step 4: Test autocomplete**

1. Type `{{` in URL bar → autocomplete dropdown appears
2. Type partial name (e.g., `{{bas`) → list filters to matching variables
3. Press Enter/Tab on a completion → variable name inserted with `}}`
4. Press `Ctrl+Space` → manually triggers completion
5. Press Escape → closes completion dropdown

- [ ] **Step 5: Test popover**

1. Click on a `{{baseUrl}}` token → popover appears below with:
   - Value input showing the resolved value
   - Scope badge (E for environment) + label
   - "Collection Environments →" link
2. Edit the value → press Enter → value saves to environment
3. Click on an unresolved `{{missing}}` → popover shows "Not set"
4. Click on a collection var → popover input is read-only

- [ ] **Step 6: Test path params**

1. Type `https://api.com/users/:userId` → `:userId` appears in violet
2. Click on `:userId` → popover opens for path param editing

- [ ] **Step 7: Test curl paste**

1. Copy a curl command: `curl -X GET https://api.example.com/users`
2. Paste into URL bar → curl import dialog triggers

- [ ] **Step 8: Test Enter to send**

1. Type a URL → press Enter → request sends (same as clicking Send)
2. With autocomplete open → Enter selects completion (does NOT send)
