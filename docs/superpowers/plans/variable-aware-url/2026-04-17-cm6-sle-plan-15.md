# CM6 Multi-Line Revert — Plan 15: Restore Monaco for Multi-Line Editors

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Revert the CM6 multi-line migration (Plans 09–12, 14) and restore Monaco as the editor for all multi-line surfaces: request body, response viewer, Git diff viewer, and conflict resolver. CM6 remains for single-line fields only (Plans 01–08).

**Architecture:** This plan restores the pre-Plan-09 state for multi-line editors. It deletes CM6 multi-line components (`MultiLineEditor`, `CM6DiffViewer`), deletes CM6 multi-line extensions (`language-detect`, `variable-hover`, `multi-line-theme`, `diff-theme`, `syntax-highlight`), restores Monaco imports in call sites, restores Monaco infrastructure files (`MonacoWrapper`, `monaco-config`, `useMonacoTheme`), restores Monaco setup in `main.tsx`, and re-adds Monaco packages.

**Tech Stack:** Monaco (`monaco-editor`, `@monaco-editor/react`), React

**Depends on:** Plans 01–08 remain intact (SingleLineEditor with CM6).
