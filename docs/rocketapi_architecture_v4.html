🚫
Domain crates never import upward
rocket-collection, rocket-environment, rocket-http etc. never import from rocket-infra, rocket-app, or src-tauri. Arrows only point down.
🚫
rocket-app never constructs infra types
All repos and executors arrive via Box<dyn Trait> constructor injection. rocket-app never instantiates FsCollectionRepo or ReqwestExecutor directly.
✅
src-tauri is the only wiring point
lib.rs is the single place where concrete infra types are instantiated and passed into services. No other file may construct them.
✅
Traits defined in domain, implemented in infra
CollectionRepository, ScriptEngine, AuditLogRepository — every trait lives in a domain crate. The infra crate only provides concrete implementations.
📋
Tauri commands are thin delegates
Command handlers in src-tauri/commands/ contain zero business logic. One line: delegate to the injected service and return the result.
📋
IPC DTOs and disk structs are always separate
#[serde(rename_all = "camelCase")] only on IPC types. Types serialized to .yml never carry this annotation — they are always distinct structs.
